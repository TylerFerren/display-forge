# Stillframe Prototype

A local-first prototype for planning church display layouts and building procedural worship backgrounds.

## Run it

Open `index.html` in a modern browser with WebGL 2 support. The prototype has no build step or package dependencies.

## Prototype features

- Arrange multiple screens and save or recall named layouts.
- Browse recipes, adjust their colors and energy, and edit shader nodes in Advanced mode.
- Preview a shared canvas across screens or separate feeds.
- Store project settings in the browser's local storage.

Video export is currently a UI prototype; rendering and download services are not connected.
